7.1 What Is Statistical Power?

Definition 7.1 The probability that a fixed-level significance test will reject \(H_0\) when a particular alternative value of the parameter is true is called the power of the test against that alternative.

\[\text{Power}=P(\text{reject } H_0 \mid H_0 \text{ false}), \qquad 0<\text{power}<1\]

High power (near 1) The test is good at detecting effects that are really there.

Low power (near 0) The test is unreliable, it usually fails to reject even when \(H_0\) is false.

Question

The power of a hypothesis test is the probability that the test will:

  • Reject \(H_0\) when \(H_0\) is actually true
  • Reject \(H_0\) when \(H_a\) is actually true
  • Fail to reject \(H_0\) when \(H_a\) is true
  • Fail to reject \(H_0\) when \(H_0\) is true

What Affects Power?

Effect size  -  Larger gaps between reality and \(H_0\) are easier to detect \(\Rightarrow\) more power.

Sample size \(n\)  -  Larger samples shrink the standard error \(\Rightarrow\) more power.

Significance level \(\alpha\)  -  A larger \(\alpha\) makes \(H_0\) easier to reject \(\Rightarrow\) more power (but more Type I risk).

Variability \(\sigma\)  -  Less spread in the data \(\Rightarrow\) narrower sampling distribution \(\Rightarrow\) more power.

You control \(n\) and \(\alpha\). The effect size and \(\sigma\) are set by the world, so sample size is your main planning lever.

7.2 Type I and Type II Errors

A hypothesis test can reach the wrong conclusion in two ways.

Type I error (\(\alpha\)) Reject \(H_0\) when \(H_0\) is true.

Type II error (\(\beta\)) Fail to reject \(H_0\) when \(H_0\) is false.

\(H_0\) True \(H_0\) False
Reject \(H_0\) Type I (\(\alpha\)) Correct (power)
Fail to reject \(H_0\) Correct Type II (\(\beta\))

A Type I error is usually treated as the more serious mistake, which is why we fix \(\alpha\) in advance (often \(0.05\)).

Power Connects to the Errors

The power of a test against an alternative is 1 minus the Type II error probability for that alternative:

\[\text{Power}=1-\beta = 1 - P(\text{Type II})\]

Reading the picture The orange tail under \(H_0\) is \(\alpha\). The red region under \(H_a\) is \(\beta\). Everything else under \(H_a\) is the power.

Question

A test fails to reject \(H_0\), but in reality \(H_0\) is false. Which error has occurred?

  • Type I error
  • Type II error
  • No error, we were cautious
  • Both Type I and Type II

Computing Power: The Recipe

  1. 1. Rejection rule in terms of the estimate. Convert the critical \(z\) (or \(z_\alpha\)) into a cutoff \(\bar{x}_*\) on the data scale using the null distribution.
  2. 2. Switch to the alternative. Assume the alternative value of the parameter is true.
  3. 3. Compute the rejection probability. Standardize the cutoff under the alternative and read off the area, which is the power.

Example: Detecting a Sweeter Reformulation

A meal-kit company quietly reformulates a sauce and asks a trained tasting panel to score the change in sweetness (positive = sweeter). If the true mean change is \(\mu=1.1\) points, will a 5% test reliably catch it?

A panel of \(n=10\) tasters scores each batch; from calibration the scores have \(\sigma=1\).

\(\sigma\) is known \(\Rightarrow\) one-sample \(z\) test, reference \(N(0,1)\).

Set-up

\[H_0:\mu = 0 \qquad H_a:\mu>0\]

  • \(n = 10,\quad \sigma = 1,\quad \alpha = 0.05\)
  • Detect the alternative \(\mu = 1.1\)

Sweetness: Cutoff to Power

Rejection Rule One-sided \(\alpha=0.05\) gives \(z_{\text{crit}}=1.645\). On the \(\bar{x}\) scale (since \(\sigma\) is known): \[\bar{x}_*=0+1.645\cdot\tfrac{1}{\sqrt{10}}\approx 0.520 \;\Rightarrow\; \text{reject if } \bar{x}>0.520\]

Find the Power Assume \(\mu=1.1\) is true and find \(P(\bar{x}>0.520)\): \[\text{power}=P\!\left(Z>\tfrac{0.520-1.1}{1/\sqrt{10}}\right)=P(Z>-1.83)=\mathbf{0.9664}\]

A 96.6% chance of correctly detecting \(\mu=1.1\). Since power \(=1-\beta\), the green and red areas add to 1: \[\text{power}=1-\beta=1-0.034=0.966\]

Check in R: Sweetness Power

Visualizing Power: The Power Curve

Power is not a single number, it is a function of the true mean. Plotting power against \(\mu\) gives the power curve.

Read it like this

  • Near \(\mu_0\), power is close to \(\alpha\) (hard to detect tiny effects).
  • As the true \(\mu\) moves away from \(\mu_0\), power climbs toward 1.
  • The orange dots mark \(\mu=0.52\) (power \(\approx 0.5\)) and \(\mu=1.1\) (power \(\approx 0.97\)).

Example: Underfilled Bottling Line

A craft-soda line should fill bottles to \(\mu_0=300\) ml, with known \(\sigma=3\) ml. Inspecting only \(n=6\) bottles, will a 5% test catch a true mean of \(\mu=299\) ml? \[H_0:\mu = 300 \qquad H_a:\mu<300 \qquad (\alpha=0.05)\]

\[\bar{x}_*=300-1.645\cdot\tfrac{3}{\sqrt6}=297.985 \quad(\text{reject if } \bar{x}<297.985)\] \[\text{power}=P\!\left(Z<\frac{297.985-299}{3/\sqrt6}\right)=P(Z<-0.83)=\mathbf{0.2033}\]

Only 20% power. With just 6 bottles this test will usually miss a 1 ml shortfall, the sample is too small.

Try bumping n to 30 or 60 and re-run, then watch the power climb as the standard error shrinks.

7.3 Using Power to Determine Sample Size

Too small Low power - real, meaningful effects slip through undetected. The study is wasted.

Too large Wasteful - extra time, cost, and participants for precision you did not need.

Power analysis finds the minimum \(n\) that detects an effect of a given size with a specified probability (power), while holding the Type I rate at \(\alpha\).

To run it you must supply three ingredients: the standard deviation \(\sigma\), the significance level \(\alpha\), and the effect size \(\mu_0-\mu_a\) you want to detect.

The Sample-Size Idea

  1. 1. Cutoff from \(H_0\). Write \(\bar{x}_*\) using the null mean and \(z_\alpha\).
  2. 2. Cutoff from the target power. Write the same \(\bar{x}_*\) using the alternative mean and \(z_\beta\) (the \(z\) giving the desired power).
  3. 3. Set the two expressions equal and solve for \(n\). Round up to the next whole observation.

One-sided sample-size formula \[n=\left(\frac{(z_\alpha+z_\beta)\,\sigma}{\mu_0-\mu_a}\right)^{2}\] where \(z_\beta\) is the standard-normal value matching the target power.

Example: Detecting a Lift in Daily Active Minutes

A product team’s app currently averages \(\mu_0=100\) daily active minutes. A new onboarding flow is believed to lift engagement. With \(\sigma=14\), they want power \(0.60\) to detect a true mean of \(\mu=103\). What is the smallest \(n\)? \[H_0:\mu=100 \qquad H_a:\mu>100 \qquad (\alpha=0.05)\]

Cutoff under \(H_0\) \(\;\bar{x}_*=100+1.645\cdot\tfrac{14}{\sqrt n}\)

Cutoff for power 0.60 \(\;P(Z>-0.25)\approx 0.60 \;\Rightarrow\; \bar{x}_*=103-0.25\cdot\tfrac{14}{\sqrt n}\)

Equate and solve \[100+1.645\cdot\tfrac{14}{\sqrt n}=103-0.25\cdot\tfrac{14}{\sqrt n} \;\Rightarrow\; n=\left(\frac{(1.645+0.25)\cdot 14}{103-100}\right)^2\approx 78.2 \;\Rightarrow\; \boxed{n=79}\]

Check in R: Sample Size for the Lift

\(n\approx 78.2\), so a minimum of 79 observations guarantees power of at least 0.60. (Using the rounded \(z_\beta=0.25\) from the table gives the same answer.)

Example: Vending-Machine Coffee

A campus vending machine advertises \(225\) ml cups (\(\sigma=7\) ml). You suspect it pours less. How many cups must you sample to reach power \(0.80\) against a true mean of \(\mu=223\) ml? (Target: \(P(Z<0.84)\approx0.80\), so \(z_\beta=0.84\).) \[H_0:\mu=225 \qquad H_a:\mu<225 \qquad (\alpha=0.05)\]

Equate the two cutoffs \(\;225-1.645\tfrac{7}{\sqrt n}=223+0.84\tfrac{7}{\sqrt n}\)

Solve for \(n\) \[n=\left(\frac{(1.645+0.84)\cdot 7}{225-223}\right)^2\approx 75.6 \;\Rightarrow\; \boxed{n=76}\]

A minimum of 76 cups delivers the desired 0.80 power against a 2 ml shortfall.

Check in R: Coffee Sample Size

power.t.test and power.prop.test automate these calculations once you know \(\sigma\), \(\alpha\), the effect size, and the target power.

Power for a Proportion: Same Logic

For a one-sided test of \(p\), the rejection cutoff uses the null standard error, but power is computed with the alternative standard error:

\[\hat p^{\,*}=p_0 \mp z_\alpha\sqrt{\tfrac{p_0(1-p_0)}{n}}, \qquad \text{power}=P\!\left(\hat p \text{ in reject region}\;\middle|\; p=p_a\right)\]

A Streaming Proportion Test

A streaming platform claims \(90\%\) of viewers finish episode 1. Researchers suspect fewer do, and test \(H_0:p=0.90\) vs \(H_a:p<0.90\) at \(\alpha=0.05\). The truth is \(p=0.85\).

The question How does the power to detect this 5-point drop change as the sample grows from \(n=50\) to \(n=200\)?

Streaming Example: Power Grows with \(n\)

\(n\) cutoff \(\hat p^{\,*}\) \(z\) under \(p=0.85\) Power
50 0.8507 \(-0.39\) 0.347
100 0.8507 \(0.02\) 0.507
200 0.8651 \(0.60\) 0.725

Same effect (a drop from 0.90 to 0.85), same \(\alpha\), only \(n\) changes. Power climbs from 35% to 73%.

Check in R: Proportion Power

How Many Viewers for Power 0.80?

Keep \(H_0:p=0.90\), \(H_a:p<0.90\), true \(p=0.85\), \(\alpha=0.05\). Set power \(=0.80\) (\(z_\beta=0.8416\)) and equate the two cutoff expressions: \[0.90-1.645\sqrt{\tfrac{0.90(0.10)}{n}}=0.85+0.8416\sqrt{\tfrac{0.85(0.15)}{n}}\]

\[\sqrt n=\frac{1.645\sqrt{0.09}+0.8416\sqrt{0.1275}}{0.05}=\frac{0.4935+0.3005}{0.05}\approx 15.88\] \[n\approx 252.2 \;\Rightarrow\; \boxed{n=253}\]

Detecting a modest 5-point drop with 80% power takes 253 viewers, far more than the 50-200 above. Smaller effects always demand larger samples.

General Power Formulas

Right-tailed, \(H_a:\mu>\mu_0\) \[\text{Power}(\mu_a)=\pi(\mu_a)=P\!\left[\,Z\ge z_\alpha+\frac{\sqrt n\,(\mu_0-\mu_a)}{\sigma}\right]\]

Left-tailed, \(H_a:\mu<\mu_0\) \[\text{Power}(\mu_a)=\pi(\mu_a)=P\!\left[\,Z\le -z_\alpha+\frac{\sqrt n\,(\mu_0-\mu_a)}{\sigma}\right]\]

Two-sided, \(H_a:\mu\ne\mu_0\) \[\text{Power}(\mu_a)=1-P\!\left[-z_{\alpha/2}+\frac{\sqrt n\,(\mu_0-\mu_a)}{\sigma}\le Z\le z_{\alpha/2}+\frac{\sqrt n\,(\mu_0-\mu_a)}{\sigma}\right]\]

What You Need to Know

Standard deviation \(\sigma\) - the spread of the variable being measured.

Significance level \(\alpha\) - the fixed Type I error rate you are willing to tolerate.

Effect size \(\mu_0-\mu_a\) - the smallest difference worth detecting.

With data in hand it is more common to report a p-value than a fixed reject/not-reject decision: it measures the strength of evidence against \(H_0\) and leaves the action up to each reader.

Chapter 7 Cheat Sheet

Quantity Formula / idea
Power \(1-\beta=P(\text{reject } H_0\mid H_0 \text{ false})\)
Type I error \(\alpha=P(\text{reject } H_0\mid H_0 \text{ true})\)
Type II error \(\beta=P(\text{fail to reject}\mid H_0 \text{ false})\)
Cutoff (right-tailed) \(\bar{x}_*=\mu_0+z_\alpha\,\sigma/\sqrt n\)
Power (right-tailed) \(P\!\big(Z\ge z_\alpha+\sqrt n(\mu_0-\mu_a)/\sigma\big)\)
Sample size (one-sided) \(n=\big((z_\alpha+z_\beta)\sigma/(\mu_0-\mu_a)\big)^2\)

Always round a computed sample size up to the next whole observation so the achieved power is at least the target.

One-slide takeaway. Power \(=1-\beta\) is a test’s ability to detect a real effect. It rises with effect size, sample size, and \(\alpha\), and falls with variability, so planning \(n\) in advance is how we guarantee a study can succeed.
