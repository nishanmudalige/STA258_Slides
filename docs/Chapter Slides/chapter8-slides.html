Why ANOVA?

Analysis of Variance, or ANOVA, is used to compare several population means.

Suppose there are \(k\) groups, usually with \(k \ge 3\).

Bad habit Run many separate two-sample tests.

ANOVA habit Start with one global test:

\[H_0:\mu_1=\mu_2=\cdots=\mu_k\]

Interpretation If the global test rejects, then at least one population mean differs.

ANOVA does not immediately tell us which mean is different. That comes later with pairwise comparisons.

One-Factor ANOVA Model

The textbook model is:

\[ Y_{ij}=\mu+\tau_i+\epsilon_{ij}, \qquad \epsilon_{ij}\sim N(0,\sigma^2) \]

where \(Y_{ij}\) is observation \(j\) in group \(i\).

Meaning of the pieces

  • \(\mu\): overall mean
  • \(\tau_i\): treatment effect for group \(i\)
  • \(\epsilon_{ij}\): random error
  • \(\mu+\tau_i\): mean of group \(i\)

Equivalent form:

\[ Y_{ij}=\mu_i+\epsilon_{ij}, \qquad \epsilon_{ij}\sim N(0,\sigma^2) \]

where \(\mu_i\) is the population mean of group \(i\).

Each observation in the same group is modeled as having the same population group mean, plus random error.

Data Structure and Notation

Group 1 Group 2 \(\cdots\) Group \(k\)
\(X_{11}\) \(X_{21}\) \(\cdots\) \(X_{k1}\)
\(X_{12}\) \(X_{22}\) \(\cdots\) \(X_{k2}\)
\(\vdots\) \(\vdots\) \(\ddots\) \(\vdots\)
\(X_{1n_1}\) \(X_{2n_2}\) \(\cdots\) \(X_{kn_k}\)
\(\bar X_1\) \(\bar X_2\) \(\cdots\) \(\bar X_k\)
\(S_1^2\) \(S_2^2\) \(\cdots\) \(S_k^2\)
\(n_1\) \(n_2\) \(\cdots\) \(n_k\)

Notation

  • \(\bar X_i\): sample mean of group \(i\)
  • \(S_i^2\): sample variance of group \(i\)
  • \(n_i\): sample size of group \(i\)

Total sample size:

\[n=n_1+n_2+\cdots+n_k\]

Overall sample mean:

\[ \bar X= \frac{1}{n}\sum_{i=1}^{k}\sum_{j=1}^{n_i}X_{ij} = \frac{1}{n}\sum_{i=1}^{k}n_i\bar X_i \]

Sources of Variation

ANOVA works by splitting the total variation into two pieces.

Within groups: error variation

\[ SSE=\sum_{i=1}^{k}(n_i-1)S_i^2 \]

This measures residual variation inside the groups.

Between groups: treatment variation

\[ SSTr=\sum_{i=1}^{k}n_i(\bar X_i-\bar X)^2 \]

This measures how far group means are from the overall mean.

If group means are far apart compared with the within-group noise, the ANOVA F statistic becomes large.

Total Variation and Decomposition

Total variation:

\[ SSTotal=\sum_{i=1}^{k}\sum_{j=1}^{n_i}(X_{ij}-\bar X)^2 \]

Decomposition identity

\[ SSTotal=SSTr+SSE \]

ANOVA asks whether the between-group variation is large relative to the within-group variation.

If all group means are similar, \(SSTr\) should be small.

If at least one group mean is far away, \(SSTr\) gets larger.

The ANOVA Table

Source df SS MS F-statistic
Treatment \(k-1\) \(SSTr\) \(MSTr=\dfrac{SSTr}{k-1}\) \(F^*=\dfrac{MSTr}{MSE}\)
Error \(n-k\) \(SSE\) \(MSE=\dfrac{SSE}{n-k}\)
Total \(n-1\) \(SSTotal\)

Mean square rule

\[ MS=\frac{SS}{df} \]

The F statistic compares treatment variation per degree of freedom with error variation per degree of freedom.

Hypothesis Test and Reference Distribution

Hypotheses:

\[ H_0:\mu_1=\mu_2=\cdots=\mu_k \]

\[ H_a:\text{at least one }\mu_j\text{ is different} \]

Test statistic

\[ F^*=\frac{MSTr}{MSE} = \frac{SSTr/(k-1)}{SSE/(n-k)} \]

Under \(H_0\):

\[ F^*\sim F_{k-1,n-k} \]

The ANOVA p-value is always a right-tail probability.

Large \(F^*\) means the treatment variation is large compared with error variation.

ANOVA P-value Visual

Example reference distribution

For \(k=3\) groups and \(n=18\) observations:

\[ df_1=k-1=2, \qquad df_2=n-k=15 \]

The shaded region is the p-value:

\[ P(F_{2,15}\ge F^*) \]

Calculation

\[ \bar x=\frac{6(1.33)+6(2.50)+6(2.67)}{18}=2.17 \]

\[ SSE=(6-1)(1.87)+(6-1)(2.30)+(6-1)(1.47)=28.20 \]

\[ SSTr=6(1.33-2.17)^2+6(2.50-2.17)^2+6(2.67-2.17)^2=6.39 \]

\[ MSTr=\frac{6.39}{2}=3.20, \qquad MSE=\frac{28.20}{15}=1.88 \]

\[ F^*=\frac{3.20}{1.88}=1.70 \]

ANOVA table

Source df SS MS F
Treatment 2 6.39 3.20 1.70
Error 15 28.20 1.88
Total 17 34.59

With \(df_1=2\) and \(df_2=15\), \(p\approx0.216\).

Since \(p>0.05\), do not reject \(H_0\). These data do not give strong evidence that the three brands have different mean fill differences from 500 ml.

Example: Campus Café Pickup Systems

A campus café wants to compare mean pickup wait time across three ordering systems.

The data are summarized by group.


System \(n_i\) \(\bar x_i\) \(s_i^2\)
Mobile order 6 7.0 2.0
Kiosk order 6 8.5 2.8
Counter order 6 10.2 3.1

Use ANOVA at the 5% level.

Calculation

\[ \bar x=\frac{6(7.0)+6(8.5)+6(10.2)}{18}=8.57 \]

\[ SSTr=6(7.0-8.57)^2+6(8.5-8.57)^2+6(10.2-8.57)^2=30.76 \]

\[ SSE=(5)(2.0)+(5)(2.8)+(5)(3.1)=39.50 \]

\[ MSTr=\frac{30.76}{2}=15.38, \qquad MSE=\frac{39.50}{15}=2.63 \]

\[ F^*=\frac{15.38}{2.63}=5.84 \]

Hypotheses

\[ H_0:\mu_1=\mu_2=\mu_3 \]

\[ H_a:\text{at least one system mean wait time differs} \]

With \(df_1=2\) and \(df_2=15\), \(p\approx0.013\).

Since \(p<0.05\), reject \(H_0\). There is evidence that not all ordering systems have the same population mean wait time.

Check in R: Summary-Statistic ANOVA

Margarine example

#| autorun: false
anova_summary <- function(n, xbar, s2) {
  k <- length(n)
  N <- sum(n)

  grand <- sum(n * xbar) / N
  SSTR <- sum(n * (xbar - grand)^2)
  SSE <- sum((n - 1) * s2)

  df1 <- k - 1
  df2 <- N - k

  MSTR <- SSTR / df1
  MSE <- SSE / df2
  Fstar <- MSTR / MSE
  pval <- pf(Fstar, df1, df2, lower.tail = FALSE)

  data.frame(grand, SSTR, SSE, MSTR, MSE, Fstar, pval)
}

out <- anova_summary(
  n = c(6, 6, 6),
  xbar = c(1.33, 2.50, 2.67),
  s2 = c(1.87, 2.30, 1.47)
)

round(out, 3)

Assumptions of ANOVA

Assumptions

  • Observations are independent.
  • Error terms, or residuals, are Normal.
  • All groups have the same population variance: \(\sigma_1^2=\sigma_2^2=\cdots=\sigma_k^2=\sigma^2\).

The common variance is estimated using the Mean Squared Error from ANOVA:

\[ \hat\sigma^2=MSE \]

This is why the denominator of the F statistic is \(MSE\): it estimates the shared within-group variance.

What If ANOVA Rejects?

ANOVA’s alternative is broad:

\[ H_a:\text{at least one mean is different} \]

So after rejecting \(H_0\), we still need to ask:

Which mean or means are different?

Pairwise comparisons

Compare the means in pairs.

For three groups:

  • \(\mu_1\) vs. \(\mu_2\)
  • \(\mu_1\) vs. \(\mu_3\)
  • \(\mu_2\) vs. \(\mu_3\)

Number of comparisons:

\[ \binom{k}{2} \]

Pairwise Confidence Intervals

For comparing two group means after ANOVA, use intervals for:

\[ \mu_i-\mu_j \]

Fisher’s LSD

\[ (\bar x_i-\bar x_j)\pm t_{1-\alpha/2,n-k} \sqrt{MSE\left(\frac{1}{n_i}+\frac{1}{n_j}\right)} \]

More power, but does not control experiment-wise Type I error.

Bonferroni

\[ (\bar x_i-\bar x_j)\pm t_{1-\alpha/(2m),n-k} \sqrt{MSE\left(\frac{1}{n_i}+\frac{1}{n_j}\right)} \]

where \(m=\binom{k}{2}\). Controls experiment-wise Type I error.

Fisher LSD vs. Bonferroni

Method Main idea Tradeoff
Fisher LSD Uses ordinary pairwise confidence intervals after ANOVA Higher power, but does not control experiment-wise Type I error
Bonferroni Makes each pairwise interval wider by adjusting for \(m\) comparisons Controls experiment-wise Type I error, but has lower power

Least significant difference

\[ LSD=t_{1-\alpha/2,v} \sqrt{MSE\left(\frac{1}{n_i}+\frac{1}{n_j}\right)} \]

Conclude two means differ if:

\[ |\bar x_i-\bar x_j|>LSD \]

Example: Phone Case Drop-Test Costs

A device lab tests four phone case designs.

ANOVA rejects the equal-means hypothesis:

\[ F^*=112.06, \qquad p<0.001 \]

Group means:

Case Mean repair cost
Slim 87.50
Rugged 113.00
Wallet 98.50
Clear 75.88

\(MSE=17.89\) and \(v=28\).

Bonferroni setup

There are:

\[ m=\binom{4}{2}=6 \]

comparisons.

Bonferroni uses:

\[ t_{1-\alpha/(2m),28} = t_{1-0.05/(12),28} =2.839 \]

For equal sample sizes \(n_i=8\):

\[ SE=\sqrt{17.89\left(\frac18+\frac18\right)}=2.115 \]

Bonferroni margin:

\[ 2.839(2.115)=6.00 \]

Question

Which phone case designs have different population mean repair costs?

Check in R: Pairwise Comparisons

Basketball Fisher / Bonferroni intervals

#| autorun: false
means <- c(Classic = 20, Streak = 25, Leaderboard = 30)
n <- c(6, 6, 6)
names(n) <- names(means)

MSE <- 2
v <- 15
alpha <- 0.05
m <- choose(length(means), 2)

pairs <- combn(names(means), 2)

out <- lapply(seq_len(ncol(pairs)), function(a) {
  i <- pairs[1, a]
  j <- pairs[2, a]

  diff <- means[i] - means[j]
  se <- sqrt(MSE * (1/n[i] + 1/n[j]))

  data.frame(
    pair = paste(i, "-", j),
    diff = diff,
    LSD_low = diff - qt(1 - alpha/2, v) * se,
    LSD_up = diff + qt(1 - alpha/2, v) * se,
    Bonf_low = diff - qt(1 - alpha/(2*m), v) * se,
    Bonf_up = diff + qt(1 - alpha/(2*m), v) * se
  )
})

round(do.call(rbind, out), 2)

Bonferroni vs. Fisher: Decision Guide

Use Fisher LSD when…

  • You want a simpler post-ANOVA comparison.
  • You accept higher experiment-wise Type I error risk.
  • Power is the priority.

Use Bonferroni when…

  • You want stronger control of experiment-wise Type I error.
  • You have many pairwise comparisons.
  • You are okay with wider intervals and lower power.

Textbook takeaway: Bonferroni corrects the multiple-comparisons problem; Fisher LSD is easier and more powerful but does not maintain the same experiment-wise error control.

Final Checklist

Before calculating ANOVA

  • Identify the response variable.
  • Identify the grouping variable.
  • State \(H_0:\mu_1=\cdots=\mu_k\).
  • Check independence, Normal errors, and equal variance.

After calculating ANOVA

  • Fill in df, SS, MS, and \(F^*\).
  • Use the right-tail F p-value.
  • Reject only when the p-value is small.
  • If ANOVA rejects, use pairwise comparisons to find which means differ.

One slide takeaway. ANOVA compares several means by asking whether between-group variation is large compared with within-group error variation.
